I build tools I use every day: systems software in C++, infrastructure for AI agents, and a few web applications. Most of it runs on my own machines — the same machines that serve these packages.

Projects

  • FSMgineC++
    A finite-state-machine engine driven by a textual FSM format, generating C++ tables for its compiled back end.
  • KitCIC++
    A C++17 CI gate engine: one binary, a per-repo gate.toml, graph outputs.
  • ComputoC++
    A sandboxed, JSON-native data transformation engine — a Lisp-like language expressed in JSON.
  • JSONFuzzC++
    A parser-agnostic, structure-aware JSON fuzzer that holds parsers to fixed-point laws.
  • NotesTypeScript
    My replacement for Dropbox Paper: Deno, Oak and Postgres, with a hybrid text/tag search — plus notes-cli, a stdlib-only terminal client.
  • TNGPlaylistsTypeScript
    Playlists of Star Trek: The Next Generation, with semantic search.
  • HermesAgentForBeginnersLua
    A book that documents learning Hermes Agent from the ground up — memory, skills, profiles, kanban — with the mistakes left in.

Package repositories

Software I package for my own fleet of Debian and Fedora machines, signed with my repository key (repo.asc, fingerprint 85C18AE4 A7B5206D BE2734C7 CE749502 49218B3C).

Debian & derivatives (amd64, arm64)

curl -fsSL https://pehkonen.dev/repo.asc | sudo tee /etc/apt/keyrings/pehkonen.dev.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/pehkonen.dev.asc] https://apt.pehkonen.dev trixie main" \
  | sudo tee /etc/apt/sources.list.d/pehkonen.dev.list

Fedora (x86_64)

sudo dnf config-manager addrepo --from-repofile=https://rpm.pehkonen.dev/fedora/pehkonen.repo
