Who's Harri

Crafting tools from the ground up

I am a software engineer and self-hosting enthusiast with a focus on systems programming, deterministic tooling, and high-performance engines. I believe that personal computing works best when software is predictable, self-contained, and respectful of the user's machines.

My primary passion lies in modern C++ (C++17/20)—authoring state machine compilers, JSON AST engines, and deterministic CI test gates where speed, memory safety, and strict invariants matter. Alongside systems work, I design and run autonomous multi-agent infrastructure (powering round-the-clock telemetry, media automation, and fleet operations across Debian, Raspberry Pi, and Fedora).

I distribute my own software across my fleet using self-hosted package repositories at pehkonen.dev, complete with compiled man pages and cryptographic signatures.

Fleet Distribution

Personal Package Repositories

I package and distribute my software for my own Debian, Raspberry Pi, and Fedora machines. Every package includes a compiled man page and is signed with my Ed25519 repository key (repo.asc).

Debian / Raspberry Pi OS (apt)
curl -fsSL https://pehkonen.dev/repo.asc | sudo tee /etc/apt/keyrings/pehkonen.dev.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/pehkonen.dev.asc] https://apt.pehkonen.dev trixie main" \
  | sudo tee /etc/apt/sources.list.d/pehkonen.dev.list
sudo apt update
Fedora / Nobara (dnf)
sudo dnf config-manager addrepo --from-repofile=https://rpm.pehkonen.dev/fedora/pehkonen.repo
